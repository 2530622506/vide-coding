# 万卷网 GESP 题源采集与题型入口

## Vision

把万卷网公开可见的 GESP C++ 1-8 级试卷作为可审计的辅助题源接入现有练习工作台，补齐选择题、判断题和编程题的题面、选项、样例、图片与知识点候选，让学生和老师能按等级、题型、算法范畴持续练习和复核。

## Goals

- MUST 从用户给定的万卷网页面及相关试卷链接发现 2025 年 6 月 GESP C++ 1-8 级试卷。
- MUST 按单选题、判断题、编程题解析题目，并保存等级、题号、题型、题干、选项、样例、图片和来源证据。
- MUST 将题目入库到现有 MySQL 题库结构，兼容 JSON fallback 和现有 API。
- MUST 为选择题、判断题新增左侧导航入口。
- MUST 将编程题归入 GESP 练习工作台对应算法范畴和题型位置。
- SHOULD 生成复核队列，标注第三方题源、知识点推断、越级或冲突标签。

## Non-Goals

- 不绕过万卷网登录、付费、次数或权限限制。
- 不把万卷网页面中不可见的答案解析当作必须采集内容。
- 不让万卷网等级或知识点覆盖官方大纲、官方真题和官方样题结论。
- 不把选择题/判断题做成脱离现有 GESP 分类目录的新产品线。

## Users

- 备考学生：按等级和题型练习选择题、判断题、编程题。
- 教学老师：快速查看同一等级下的知识覆盖和题型分布。
- 内容维护者：复核第三方题源、修正知识点标签、处理图片和版权状态。

## Success Metrics

- 1-8 级页面发现率达到 100%，每级题目总数与页面统计一致。
- 每道选择题 MUST 有 A/B/C/D 等选项结构；每道判断题 MUST 有标准二元选项；每道编程题 SHOULD 有样例输入输出。
- 每道题 MUST 有至少 1 条 source_versions 记录。
- 编程题在练习工作台中按算法范畴可见，选择题和判断题可通过左侧导航进入。
- dry-run 报告能列出重复题、缺字段、图片失败、未分类知识点和待复核项。

## Multi-Perspective Synthesis

产品视角：题型入口解决的是学生练习路径，不应破坏当前“等级 -> 算法范畴 -> 题型 -> 题目”的主信息架构。

技术视角：现有 MySQL 表和 `detail_json` 已能容纳大部分字段，优先新增 ingestion 脚本和 API 过滤能力，减少 schema 迁移风险。

用户视角：选择题/判断题需要快速刷题入口；编程题更依赖算法归类、样例和 IDE，因此应该继续回到练习工作台的算法位置。

合规视角：万卷网页脚声明其为信息共享平台且来源权属可能不确定，因此第三方题面、图片和知识点必须带版权复核状态和可回滚来源。
