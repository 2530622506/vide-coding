# 面向海外消费者的商品选购 Web 应用

## 目标与用户价值
制作一个可向客户演示的消费者商品选购 Web 应用，让美国消费者能够在桌面和手机上顺畅地发现、筛选、了解并将家居与日常生活精选商品加入购物车。当前阶段完成规划和技术选型，不编写应用源码；实现阶段以体验完成度、交互可靠性和代码可维护性优先，不追求功能数量。

## 背景与约束
- 需求依据为仓库根目录 `面试题.md`：必须使用 React；支持桌面和手机；商品可用模拟数据；不要求后端、登录或真实支付；允许组件库和公开资料；不得使用现成网站/商城模板或已有项目成品，可用官方脚手架初始化空项目。
- 题目交付要求包括完整源码、依赖声明、启动说明，以及简短交付说明（完成内容、实际验证场景、已知问题、主要取舍）。线上部署为加分项，不替代核心功能。
- 评价重点是业务理解、功能正确性、使用体验、代码质量和交付完整度；功能数量不是主要评价依据。
- 当前仓库没有应用源码或 `package.json`；存在 Trellis 初始化生成的前后端规范目录和另一个进行中的 `00-bootstrap-guidelines` 任务。本任务只负责本应用规划/实现，不修改 Bootstrap 任务。
- `maestro explore` 因本机 CLI 的 Node.js/Undici 运行时错误无法启动；经用户同意，已通过直接读取仓库文件检查需求与现状。

## 已确认产品与技术方向
- 产品方向：独立设计的家居与日常生活精选商店，不做海量综合商城或多卖家 marketplace。
- 首发市场：美国；英文界面；美元（USD）展示。不承诺多语言、多地区定价或税费计算。
- 前端：React + TypeScript + Vite；不要求 SEO、SSR 或后端服务。
- 样式与组件：Tailwind CSS + 精选 shadcn/ui 基础组件；品牌化页面和商品组件自行设计，不套用商城模板。
- 路由：React Router。首页、商品列表、商品详情和购物车使用独立 URL；购物车另提供快速 Drawer/Sheet 预览。
- 状态：Zustand 管理购物车，使用 `localStorage` 在当前浏览器持久化；不登录、不跨设备同步、不模拟服务端库存。
- 动效：CSS 处理基础 hover/focus/颜色反馈，Motion for React 用于关键状态、面板和布局转场。默认呈现明显但流畅的高级动效，避免无意义或阻塞操作的长动画；可提供系统减少动态效果偏好兼容，不影响默认效果。
- 图片：使用用户认可的本地 Pexels 授权图片作为模拟商品示意素材，不抓取零售商受版权保护的商品摄影；交付图片来源和许可记录。图片不应暗示实际商品实拍或品牌背书。
- 自动化测试不纳入本次交付，由用户自行测试。实现阶段仍需运行可用的静态检查和生产构建，并诚实记录实际验证与已知问题。

## 功能需求
- **FR-1 商品发现：首页**提供精选商品/分类入口和清晰的进入商品列表路径，体现统一的生活方式品牌视觉。
- **FR-2 商品列表：**支持查看模拟商品卡片；支持关键词搜索、品类/价格/颜色/材质筛选，以及推荐/上新/价格排序。移动端筛选需适配触控，展示已选条件并能应用或清除。
- **FR-3 商品详情：**每个商品有独立 URL，展示图片、名称、美元价格、简要描述、评分/评价等演示数据，以及适用的规格/变体信息；可将商品加入购物车。
- **FR-4 购物车：**可查看商品、规格、数量和小计；可调整数量、移除商品、继续购物；页头购物车数量和抽屉预览随状态更新；刷新后当前浏览器中的购物车仍保留。
- **FR-5 响应式与动效：**关键页面适配桌面与手机；导航、筛选、加购、购物车更新等交互反馈明确、连贯、流畅。
- **FR-6 可维护实现：**页面、领域组件、数据/逻辑和共享 UI 按职责拆分；使用类型安全的数据模型；必要注释解释非显然的业务规则或实现取舍，不写逐行赘述注释。
- **FR-7 资产与交付：**商品图片在项目本地稳定加载并有来源/许可清单；源码包含依赖声明、启动方式和交付说明。

## 验收标准
- **AC-1（FR-1、FR-2）：**用户可从首页进入商品列表，使用关键词、已确认筛选维度及排序找到商品；空结果时有清晰反馈和恢复方式。
- **AC-2（FR-3、FR-4）：**商品卡片进入对应详情；加购后导航数量、抽屉和购物车页面一致；数量增减、移除和金额小计工作正确；刷新后购物车恢复。
- **AC-3（FR-5）：**首页、列表、详情、购物车在桌面和窄屏布局下均可操作；筛选面板、加购和购物车状态变化有及时反馈，动效不阻塞主要操作。
- **AC-4（FR-6）：**代码按职责拆分，模拟商品数据与 UI 分离，购物车和筛选逻辑不集中塞进单个页面；关键规则有必要注释。
- **AC-5（FR-7）：**项目可按说明安装依赖并启动；商品图片来源/许可可追溯；交付说明仅列出实际运行过的验证和已知问题。
- **AC-6（范围）：**不包含后端、登录、真实支付、结账/订单提交或现成商城模板；自动化测试不是本次交付要求。

## 范围外
- 后端、数据库、账号体系、跨设备购物车同步、实时库存/运费/税费、真实支付及下单。
- SEO/SSR、多语言、多地区本地化。
- 大型商城级搜索推荐、广告、卖家/店铺体系、复杂个性化。
- 抓取零售商或竞争网站的受版权保护商品图片。
- 自动化测试套件（用户会自行测试）。
