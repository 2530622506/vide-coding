有限小数判断

质因数分解 · 数论基础 · 官方题源对齐

题目

给定一个最简分数 a / b，判断它能否化为有限小数。若分母只包含质因数 2 和 5，则可以化为有限小数。

A. 只含 2 或 5
B. 只含 2 和 5
C. 含任意质因数
D. 分子小于分母

解题线索

3 步
1. 先约分到最简形式用 gcd 消去分子分母的公共因子。
2. 不断除以 2 和 5分母剩余为 1 时，可以表示为有限小数。

参考代码有限小数判断
finite-decimal.cppC++17
#include <bits/stdc++.h>
using namespace std;

int main() {
  long long a, b;
  cin >> a >> b;
  long long g = gcd(a, b);
  b /= g;

  // 有限小数只允许分母剩下 2 和 5
  while (b % 2 == 0) b /= 2;
  while (b % 5 == 0) b /= 5;

  cout << (b == 1 ? "YES" : "NO");
}

复杂度约分和除因子均为 O(log n)，适合移动端先读思路再回到 IDE 练习。
